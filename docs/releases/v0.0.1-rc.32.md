## Mensagens de voz

- Com o rascunho vazio, use o microfone para gravar nas conversas que aceitam anexos. O campo mostra o tempo e a forma de onda durante a gravação.
- Ao parar, ouça a prévia, descarte a gravação para refazer ou envie a mensagem.
- Nos áudios compatíveis, o balão mostra a forma de onda e a duração total. Abra o menu da mensagem para **Baixar áudio**.

## Conversas e configurações

- O botão para voltar às mensagens mais recentes mostra quantas mensagens estão não lidas.
- Se uma conexão salva no desktop passar a exigir autenticação, entre pelo navegador ou informe uma chave de acesso.
- Use **Configurações → Motor** para sair do Oiê hospedado e ajustar a retenção de mensagens. O gerenciamento dos arquivos baixados fica em **Este dispositivo** quando o motor é local.
