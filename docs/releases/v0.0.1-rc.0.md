# Oiê v0.0.1-rc.0

This release candidate packages the existing XMPP chat app as a standalone
Wails desktop application for macOS Apple Silicon and Ubuntu Linux x86_64.
The engine, retained SQLite history and Goshtoso interface run in one process.
Closing the window keeps the engine running; use Quit to stop it.

Packages and the installer are available below.

## Install

Download the installer to a file, then run it as your current user:

```sh
curl --fail --location --proto '=https' --proto-redir '=https' \
  --output oie-install.sh \
  https://github.com/araihu/oie/releases/download/v0.0.1-rc.0/install.sh &&
sh ./oie-install.sh --version v0.0.1-rc.0
```

The defaults are `~/Applications/Oie.app` on macOS and `~/.local` on Linux.
`--prefix DIR` changes that location. Quit before updating and run the installer
again with the desired version. App data and preferences remain in their
separate profile directory.

Ubuntu 24.04 needs `ca-certificates`, `libgtk-4-1`, `libwebkitgtk-6.0-4` and
`libsoup-3.0-0`. Prebuilt packages need no Go or development headers. FFmpeg is
optional and installed separately. The installer checks dependencies and archive
checksums; it does not invoke `sudo` or install system packages. See the
[installation guide](../installation.md) for prerequisites, first open and removal.

## Known limits

- Initial room-history recovery can delay useful access to conversations.
  [B25](../history-bootstrap-discussion.md) must be resolved before the first
  alpha, `v0.0.1`; rc.0 keeps the current behavior.
- End-to-end encryption, outgoing attachment uploads, schedules, device sync and
  PWA/offline queues remain outside this version.
- The macOS bundle is ad-hoc signed, without Developer ID signing or notarization.
  Follow [Apple's first-open procedure](https://support.apple.com/en-us/102445)
  when needed. The installer keeps Gatekeeper and quarantine intact.
- Custom macOS profiles do not yet have fully isolated native website storage.
  The initial target is a normal single-profile installation.
- The current flat macOS icon remains; icon variants are backlog B24.

Oiê is [Apache-2.0 licensed](../../LICENSE). Packages include third-party license
notices. See [desktop verification](../desktop.md#verification) for the existing
native checks and their scope. The exact release archives passed installation
and reinstallation while retaining SQLite identity and user files. The macOS
bundle opened through LaunchServices on Apple Silicon. The Linux executable
painted the Oiê interface and exited through Ctrl+Q in an Ubuntu 24.04 amd64
runtime container under emulation, with no Go, compiler or development headers.
