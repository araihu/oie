# Oiê v0.0.1-rc.1

## Changes since rc.0

- Open and use rooms while Oiê retrieves older history in the background. Recent
  messages load first. Each room can fetch older history on demand, and room
  search can include results from supported XMPP archives.
- Use Gajim-style nickname completion in rooms and emoji shortcode completion
  in the composer. Incoming mentions highlight the message and mark the
  conversation when it is unread.
- React to messages in semianonymous XMPP rooms that provide verified occupant
  IDs. The reaction button opens a compact set of emoji choices first.
- Collapse or resize the navigation sidebar, switch conversations with less
  waiting, and find appearance and language options in tabbed settings.
- Oiê is now distributed under GNU GPLv3 only. Bundled third-party assets keep
  their respective licenses. [License](https://github.com/araihu/oie/blob/v0.0.1-rc.1/LICENSE)

[Compare rc.0 and rc.1](https://github.com/araihu/oie/compare/v0.0.1-rc.0...v0.0.1-rc.1)

## Install or update

Quit Oiê before updating. Download the installer and run it as your current
user. Your existing profile and preferences are preserved.

```sh
curl --fail --location --proto '=https' --proto-redir '=https' \
  --output oie-install.sh \
  https://github.com/araihu/oie/releases/download/v0.0.1-rc.1/install.sh &&
sh ./oie-install.sh
```
