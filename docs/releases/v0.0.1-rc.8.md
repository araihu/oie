# Oiê v0.0.1-rc.8

The upstream copyright terms for Oiê and Goshtoso artwork are Apache-2.0.
The packages include the Noto Emoji attribution and the MIT notice for the
Babel and Regenerator helpers bundled with focus-trap.

The corresponding source includes the vendored Go modules, editable browser
and artwork sources, and native build inputs. The PDF.js test corpus is
excluded. The server image includes third-party notices and identifies the
verified source archive for Linux amd64 and arm64.

The catalog keeps the current row anchored during pagination.
