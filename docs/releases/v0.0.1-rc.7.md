# Oiê v0.0.1-rc.7

This release uses the published Goshtoso v0.6.2, Margo v0.0.36 and
oapi-cli-gen v0.1.0 tags. Goshtoso's demonstration photographs are distributed
with its demo site. The generator and the runtime it copies into the CLI are
available under MIT. Oiê remains under the GNU GPLv3.

Appearance preferences now persist across background refreshes. The bundled
engine contract is v0.30.1.
