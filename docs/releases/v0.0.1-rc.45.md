## Conversas no celular

- No celular, **Voltar para as conversas** reabre a lista de conversas sem esperar pela rede. Ao trocar de conversa, o Oiê reaproveita a lista que já está na tela.
- O Oiê carrega as ações de cada mensagem quando você abre o menu. **Copiar mensagem original** continua disponível se a conexão cair.
- Nos detalhes da conversa, ative **Manter disponível sem conexão** para guardar uma cópia das mensagens recentes neste navegador. Sem conexão, você pode buscar texto em todas as conversas salvas ou abrir uma conversa para buscar só nela.

## Backup do perfil

Com o motor parado, use `oie backup create` para criar um arquivo ZIP e `oie backup verify` para verificá-lo. Você pode incluir a mídia baixada. O comando `oie backup restore` mescla os dados em um perfil novo ou existente. Os envios recuperados ficam pausados até você revisá-los.

Para restaurar com a rc.45, crie o ZIP com essa versão a partir do perfil original. A restauração exige o esquema de banco 54. [Guia de backup e restauração](https://github.com/araihu/oie/blob/v0.0.1-rc.45/docs/installation.md#create-and-verify-a-manual-backup)

O chart Helm 0.2.23 usa a imagem desta versão por padrão.
