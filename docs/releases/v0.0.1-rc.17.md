## Novidades

- No desktop, abra **Configurações → Geral → Motor** para escolher **Local** ou **Remoto**. Local é o padrão. No modo remoto, informe o endereço HTTP(S) do motor hospedado e salve. O Oiê verifica a conexão e guarda a escolha por perfil.
- **Apagar todos os dados** fica em **Configurações → Geral → Ações destrutivas**. Digite `delete` para confirmar a exclusão.
- Os ícones e rótulos de **Aparência** estão centralizados, com mais espaço entre o título e as opções.

O acesso à API do motor remoto é aberto nesta versão. Use um túnel SSH ou uma rede privada para restringir o acesso.
