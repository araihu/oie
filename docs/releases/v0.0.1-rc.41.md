## Conversas recentes sem conexão

- No Oiê local, o navegador guarda o texto das conversas que você abriu recentemente. Quando a conexão cair, abra uma delas pela lista **Conversas recentes** na tela **Sem conexão**.
- Toque em **Tentar novamente** para voltar à conversa quando o Oiê estiver acessível.

O chart Helm 0.2.19 usa a imagem desta versão por padrão.
