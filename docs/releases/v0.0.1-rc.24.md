## Diagnóstico

- Abra **Configurações → Diagnóstico** para consultar eventos do Oiê por período. Cada linha mostra o evento, a gravidade, o horário e o componente. Abra uma linha para ver os campos do registro.
- Use **Copiar** ou abra a seta ao lado de **Copiar** e selecione **Baixar** para salvar o trecho como `oie-diagnostics.jsonl`. O registro exclui mensagens, rascunhos, credenciais e dados de contas.
- No desktop, **Este dispositivo** reúne os eventos locais. Para consultar um servidor configurado, selecione **Servidor** e informe a chave de diagnóstico quando solicitada.
