## Novidades

- O Oiê pode ser instalado no Kubernetes com o chart Helm `charts/oie`. O chart guarda contas, histórico e mídia em um volume persistente.
- Acesse a interface com `kubectl port-forward` ou configure Ingress ou Gateway API. A opção `httpRoute` conecta o Oiê a um Gateway existente. Para acesso remoto, configure HTTPS e autenticação no Gateway ou no proxy.
