# Oiê v0.0.1-rc.3

The desktop packages include the third-party license notices for the bundled
icons and JavaScript. The packages omit the 14 demonstration images previously
embedded by Goshtoso. Oiê is licensed under GNU GPLv3 only. The runtime copied
into the command-line client is available under MIT.

[Compare rc.2 and rc.3](https://github.com/araihu/oie/compare/v0.0.1-rc.2...v0.0.1-rc.3)

## Install or update

Quit Oiê before updating. Run the installer as your current user. Your existing
profile and preferences are preserved.

```sh
curl --fail --location --proto '=https' --proto-redir '=https' \
  --output oie-install.sh \
  https://github.com/araihu/oie/releases/download/v0.0.1-rc.3/install.sh &&
sh ./oie-install.sh
```
