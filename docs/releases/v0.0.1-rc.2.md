# Oiê v0.0.1-rc.2

## Changes since rc.1

- Schedule messages with text, links and supported attachments. Use the
  Scheduled view or a conversation's drawer to edit, reschedule, cancel or send
  a pending message now. Oiê sends due messages when its engine is running and
  the account can send.
- Review first-time direct conversations and XMPP room invitations before
  opening them. Accept, join or archive the request from the conversation.
- Create persistent rooms on supported XMPP services. Open an invitation link
  to preview the room and choose an account before joining. If an occupied
  nickname is rejected, choose a different nickname and retry.
- Filter global search by account and result type. Message results show
  highlighted matches and previews of shared content. Search and navigation
  preserve more of your place in the conversation while you browse.

[Compare rc.1 and rc.2](https://github.com/araihu/oie/compare/v0.0.1-rc.1...v0.0.1-rc.2)

## Install or update

Quit Oiê before updating. Download the installer and run it as your current
user. Your existing profile and preferences are preserved.

```sh
curl --fail --location --proto '=https' --proto-redir '=https' \
  --output oie-install.sh \
  https://github.com/araihu/oie/releases/download/v0.0.1-rc.2/install.sh &&
sh ./oie-install.sh
```
