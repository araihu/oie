## Mídia e conversas

- Reproduza áudios diretamente nas conversas. Abra o menu da mensagem para baixar o arquivo.
- Em **Configurações → Este dispositivo**, escolha por quanto tempo o Oiê guarda os arquivos baixados ou remova todos de uma vez.
- O Oiê verifica os arquivos completos quando o remetente informa um resumo criptográfico compatível. Se o arquivo não corresponder, o download falha.
- Ao abrir uma conversa com mensagens não lidas, você chega à primeira delas. Use **Ir para as mais recentes** para voltar ao fim.

## Oiê hospedado

- Proprietários podem entrar pelo provedor OIDC. Nas configurações do desktop, use a URL HTTPS e uma chave de acesso para conectar ao motor hospedado.
- O chart Helm 0.2.7 usa a imagem deste RC e aceita o segredo OIDC de um Secret do Kubernetes.
