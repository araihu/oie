## Notificações e perfil

- Em **Configurações → Este dispositivo → Notificações**, use **Escolher arquivo** para definir um toque de até 5 MB. O Oiê usa os primeiros dois segundos e salva o toque no dispositivo. Use o botão de reprodução para ouvir ou o **X** ao lado do arquivo para voltar ao Oiê.
- Em **Trocar de conta → Gerenciar contas**, abra o **Perfil** da conta para editar o nome mostrado no Oiê e conferir a foto selecionada antes de salvar.
